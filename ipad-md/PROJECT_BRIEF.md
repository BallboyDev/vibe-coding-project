# iPad 앱 프로젝트 기획서

## 1. 프로젝트 개요

### 앱 이름

- edit-md

### 한 줄 설명

- iPad 기반의 텍스트 파일 수정 앱

### 앱을 만드는 이유

- 기존 iPad에서는 일반 텍스트 파일이나 마크다운 파일의 생성, 수정 지원이 부족한 점을 개선하기 위한 iPad용 텍스트, 마크다운 파일 에디터 어플리케이션 개발

### 사용 환경

- 주요 기기: iPad
- 지원 방향: 가로 모드
- 인터넷 필요 여부: 불필요
- 로그인 필요 여부: 불필요

## 2. 핵심 목표

### 첫 번째 버전의 목표

- 가장 기본적인 아이패드에 저장된 텍스트 파일의 생성, 수정, 저장 기능

### 반드시 포함할 기능

- 기능 1: 로컬 및 iCloud 기반의 경로 탐색
- 기능 2: 파일 읽기
- 기능 3: 파일 생성 및 수정, 저장

### 나중에 추가할 기능

- 기능 1: 파일 확장자에 따른 하이라이팅 기능
- 기능 2: 문서 전체의 미니맵 지원
- 기능 3: 문서 템플릿 생성, 저장 기능

## 3. 앱 구조

### 추천 기본 구조

- iPad에 적합한 `NavigationSplitView` 기반 구조
- 왼쪽: 사이드바 또는 목록
- 오른쪽: 선택한 항목의 상세 화면 또는 편집 화면
- 상단: 주요 작업 버튼

### 주요 화면 목록

| 화면 이름 | 목적 | 주요 기능 |
| --- | --- | --- |
| 홈 / 목록 화면 | 전체 항목을 보여줌 | 검색, 추가, 선택, 삭제 |
| 상세 / 편집 화면 | 선택한 항목을 확인하거나 수정 | 제목 수정, 내용 수정, 저장 |
| 설정 화면 | 앱 설정 관리 | 테마, 데이터 관리, 앱 정보 |
